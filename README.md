# 하츄핑 좀비 레이드 3D

브라우저에서 바로 돌아가는 3D 좀비 생존 게임. 파일 하나(`index.html`)가 전부다.
경준이와 아빠가 같이 만든다.

## 실행

- 폰·PC 어디서든: https://minsfa.github.io/hachuping-zombie-raid/
- 로컬: `index.html`을 더블클릭해서 브라우저로 연다. 설치할 것 없음.

## 조작

| 동작 | 키보드 | 터치(폰) |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 드래그 |
| 시점 회전 | Q / E, 마우스 드래그 | 화면 오른쪽 드래그 |
| 무기 바꾸기 | 1 · 2 · 3 | 아래 버튼 |
| 상점 / 악당 대화 | B / V | 아래 버튼 |
| 창 닫기 | ESC | ✕ 버튼 |
| 시작 / 재부팅 | Enter | 버튼 |

사격은 가장 가까운 좀비에게 자동.

## 게임 규칙

- 웨이브 30까지. 5웨이브마다 보스.
- 낮 3분 / 밤 2분. 밤엔 좀비가 빨라지고 피해 2배.
- 좀비를 잡으면 코인. 코인으로 속도, HP, 부하 로봇, 에너지건을 산다.
- 잡은 좀비는 아군 로봇으로 바뀐다(최대 12기).

## 같이 만드는 방법

1. 하고 싶은 아이디어는 **이슈**에 한 줄로 적는다. (예: "보스가 레이저를 쏘게")
2. 고칠 때는 `index.html`을 바꾸고, 브라우저에서 새로고침해서 확인한다.
3. 되면 커밋한다. 메시지는 한 줄: 무엇을 바꿨는지.
4. 막히면 Gemini나 Claude에게 파일을 통째로 보여주고 물어본다.

## 역사

- 2026-10-19 첫 버전. Gemini로 만든 원본에서 오타 한 줄(`Props: {`) 때문에 전체가 멈춘 걸 고치고, 재부팅 버그 수정, 키보드 조작 추가.
